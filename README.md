# 东京云服务器：从线路、流量到价格，一次看懂怎么选东京节点

想买东京云服务器，真正需要先搞清楚的通常不是“哪家 CPU 更快”，而是三个问题：服务器主要服务谁、国内访问是否重要、每个月到底会跑多少流量。

东京节点的优势很明确：它位于东亚核心互联位置，对日本本地用户很近，同时也覆盖韩国、东南亚以及中国大陆方向。问题也同样明显——**“东京机房”本身并不等于“国内访问快”**。不同服务商、不同上游线路、甚至同一家服务商的不同网络系列，都可能让实际体验出现明显差异。

DMIT 当前的东京产品正好把这个差异摆在了台面上：同一个 Tokyo 节点，Premium 和 Tier 1 是两套完全不同的网络思路。当前官网公开的东京云实例价格也从每月 **$6.90** 的 Tier 1 TINY，到每月 **$829.90** 的 Premium GIANT，跨度非常大。下面按真实购买逻辑拆开讲，而不是只盯着一个“最低价”。

## 东京云服务器适合哪些业务

如果主要用户就在日本，东京节点的地理位置本身就有优势。做日本站、电商后台、API、游戏服务、监控系统、远程开发环境时，把计算资源放在东京可以减少客户端与服务器之间的物理距离。

但假如你的主要用户在中国大陆，选型逻辑就会变成“东京 + 什么线路”，而不是单纯“东京”。

DMIT 当前对东京节点的官方定位是东亚节点，提供面向中国及亚洲区域优化的网络，并把东京到中国大陆的参考延迟定义为“东京至上海”的测量值。官网同时明确说明，真实延迟会随着接入网络、线路和时间段而变化，因此不能把页面上的参考值理解成每个用户每天都能固定跑出来的数字。

这也是为什么同样是东京 VPS，有的人关心的是日本本土低延迟，有的人却把中国电信、联通、移动的路由表现放在第一位。

从当前 DMIT 的网络定义来看，大致可以这样理解：

**Premium** 面向需要中国大陆及亚太方向优化路由的业务，官方说明包含 China Telecom CN2 GIA，并强调更低延迟、更少跳数以及更低丢包。

**Tier 1** 则更偏向亚太和美洲之间的国际互联，不针对中国大陆做专门优化，成本也低得多。官网把它对应到备份、归档、CI/CD、DevOps、通用计算等对中国大陆线路没有特殊要求的场景。

所以，所谓“东京云服务器怎么选”，第一步其实不是挑 TINY、STARTER 还是 MINI，而是决定你是不是需要 Premium 网络。

这不是简单的“多几个 CPU、少几个 GB”的区别。Premium 的定价核心很大程度上来自网络路线。

DMIT 当前对 Premium 的描述是，它将 Tier 1 与 Premium Transit 结合，并包含中国电信 CN2 GIA；官网把它用于面向中国大陆及亚太访客的网站、电商、流媒体、低延迟游戏服务以及需要稳定中国线路的跨境应用。

Tier 1 的定位则完全不同：它强调亚太、北美和欧洲之间的国际路由，不提供专门的中国路由增强，因此更适合备份、归档、CI/CD、监控、DevOps 和一般计算任务。

换句话说，**如果你的业务主要在日本、韩国、东南亚，或者服务器只是一个普通的国际业务节点，Premium 的网络成本未必有必要承担。**

但如果中国大陆用户是业务的重要组成部分，线路因素就值得单独付费。

## TINY、STARTER、MINI，到底差在哪

如果已经决定买东京节点，下一步就是容量。

对于轻量级项目，TINY 通常是一个容易理解的起点：1 vCPU、1GB 内存、20GB SSD。Premium TINY 当前价格是 $21.90/月，Tier 1 TINY 则是 $6.90/月，但两者的网络定位完全不同。

STARTER 把内存提升到 2GB，SSD 提升到 40GB。Premium 的 STARTER 为 $45.90/月，Tier 1 STARTER 为 $12.90/月。对于普通 Web 服务、轻量 API、开发环境或者个人项目来说，2GB 往往比 1GB 更好管理，尤其是在运行多个常驻进程时。

MINI 则进一步增加到 2 vCPU。Premium MINI 当前为 4GB 内存、60GB SSD、2000GB 流量，价格 $89.90/月；Tier 1 MINI 同样是 2 vCPU、2GB 内存、60GB SSD，但流量额度达到 8000GB，价格只有 $21.90/月。

这恰恰说明一个常见误区：**不能拿“MINI”这个等级名称直接横向比较。**

同一个 MINI，在不同网络系列里，内存、流量甚至价格都可能不同。

如果你需要的是大量流量而不是高规格 CPU，T1 的设计明显更偏向这个方向；如果你真正需要的是中国大陆方向的网络质量，那么把预算从 $21.90 增加到 Premium MINI 的 $89.90，买到的主要并不是“四倍计算能力”，而是更偏向 Premium 路由的网络定位。

## 流量比 CPU 更容易被忽略

选东京云服务器时，很多人先看：

> 2 核还是 4 核？

但实际账单更容易出问题的，往往是：

> 2TB 够不够？

DMIT 当前文档明确说明，流量额度会按月自动重置；多数标准套餐还支持付费重置额度。不同套餐采用的流量计费模式也可能不同。

因此，网站、API、游戏服、镜像下载、视频分发、备份服务器等业务不能用同一个标准。

比如一个每天几百名访问者的网站，2TB 可能绰绰有余；一个频繁同步数据、分发安装包或跑大文件传输的服务，2TB 很快就会成为瓶颈。

尤其是 T1 系列当前公开的额度明显高于同级别 Premium。例如 T1 STARTER 是 4000GB Max (IN, OUT)，Premium STARTER 为 1000GB；T1 MICRO 为 16000GB，而 Premium MICRO 为 4000GB。

因此，**不要只看“每月多少钱”，要看“每 TB 流量需要支付多少钱”。**

## 超出流量以后会发生什么

DMIT 的帮助中心目前把流量超额规则分成三类：超额暂停、超额限速，以及没有限制。具体采用哪一种，要看套餐本身。

帮助文档同时指出，有些标准套餐可以付费重置流量额度，并在控制面板查看下一次自动重置时间。

这意味着购买前最好确认两个问题：

1. 这个套餐的流量是双向计费，还是 Max (IN, OUT)？
2. 超额后是暂停、限速，还是没有限制？

对于线上业务来说，这两个问题甚至比“SSD 是 60GB 还是 80GB”更重要。
